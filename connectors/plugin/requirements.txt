# Shared dependencies of the connectors plugin: none.
#
# The shared code imports only the standard library plus fastapi and pydantic,
# which myagent's own virtualenv already provides — it runs in that process.
# A channel's dependencies live in its own folder
# (myagent_connectors/channels/<type>/requirements.txt) and are installed by
# connectors/install.sh, so a channel can be added or removed without touching
# what the others need.
